# 高中蹭饭图生成器 · 使用说明

最终交付物：**`D:\HKStudy\ProjectForFun\蹭饭图.html`**（单文件、完全离线，双击用浏览器打开即用）。

## 快速开始

1. 打开 HTML 文件（推荐 Chrome / Edge）。
2. 左侧面板填写标题信息（届次、高中、所在地、任课老师、备注）。
3. 名单导入：
   - **手动添加**：输入姓名 + 院校，回车即可；
   - **Excel 导入**：支持 .xlsx / .xls / .csv（自动识别 GBK/UTF-8），表头自动模糊匹配（姓名/大学/录取院校等），无法判断时弹出列映射对话框；未识别院校所在省份时弹出「省份补全」对话框。
4. 点击 **「搜索分数线」** 自动联网抓取各院校在本省的最低录取分数线（多代理 + 多引擎，抓不到的可手填，或用「AI 补全」：复制提示词 → 把 AI 返回的 JSON 粘贴回来）。
5. 右侧编辑区微调：拖动移动、四角缩放、方向键微调、吸附参考线、属性面板改数值、锁定/层级/一键复位、布局模板保存与套用。
6. 导出：**PNG（1x/2x/4x）**、**PDF**、**打印**。

## 省内排序与分栏

- 同一省份内按院校在本省的最低录取分数线**降序**排列，无分数的排最后，同分按姓名拼音。
- 省份分栏默认按**人数**从多到少；勾选「按地理分区」后改为 华北→东北→华东→华中→华南→西南→西北 顺序。
- 勾选「行内显示分数线」可在每行院校后显示分数。
- 分数线统一在**「分数线」页签**维护（网页搜索 / AI / 手填 / CSV），「名单」页只管姓名、院校、省份三列，不重复显示分数。

## 主题与字体

- 6 套配色主题 + 自定义取色器；标题 5 种艺术字（渐变 / 描边空心 / 立体投影 / 柔光 / 印章）。
- 字体列表读取本机已安装的中文字体，选择即预览。
- 数据自动保存在浏览器 localStorage，关闭重开不丢（旧版存档打开时自动补齐新增字段）。

## 画布尺寸

- 预设：A4 (1240×1754)、A3 (1754×2480)、16:9 (1600×900)；也可在下方两个输入框直接填宽高（像素，最小 400），回车或点击别处即应用。
- 选「1:1.414 比例」会保持当前宽度、按比例换算高度；尺寸与所选预设不符时下拉自动显示「自定义」，所见即真实尺寸。
- 切换尺寸会自动重新排版（与新画布适配）；**尺寸没变时不会动你的手动排版**——重复选中当前预设不会重置已拖好的元素位置。

## 背景图片与不透明度

- 「外观」页可导入背景图片，支持 **png / jpg / webp / gif / bmp / svg**；显示方式：铺满（裁切）、完整显示、平铺；背景透明度 5%–100% 独立调节。
- **元素不透明度**：外观页滑杆一键调整全部元素；也可以点选单个元素，在右侧「属性面板」单独设不透明度（5%–100%）。

## 省份栏头 / 名单行样式

- **省份栏头** 6 种预设：实心、渐变、描边、下划线、反白、胶囊；圆角、头背景色、头文字色可调。
- **名单行** 4 种预设：简洁、分隔线、斑马纹、卡片行；分隔线颜色/线宽、斑马纹颜色、行圆角可调。
- 颜色未手动指定时随主题自适应；预设与参数即时预览并自动保存。

## 地图说明

完整中国地图：含台湾省、香港、澳门、南海诸岛（九段线 + 南海诸岛小图插框），省面按录取人数着色（可看左下角图例），不标注城市点；所有文字信息块位于地图外，用引线连到对应省份。

- **角度预设** 4 种：平面、微俯、俯视、侧倾；俯仰角（0°–70°）、侧转（±25°）滑杆微调。引线端点会按透视投影自动对齐，导出 PNG/PDF/打印与屏幕所见一致。自动取景同样计入透视变换的实际显示位置——倾斜状态下省界、海岸线、南海诸岛不会被挤出画布裁掉；南海诸岛小图固定在框角，不随地图倾斜。
- **重点强调**：勾选「缩放聚焦到有学生的省份」后，按有学生省份的**完整轮廓**（外加 12% 余量，保证省界不被裁切）自动取景放大，学生变动或画布尺寸变化时自动重聚焦；取消勾选恢复完整中国视角。「重新聚焦」按钮可手动刷新。**聚焦开启时，缩放 / 水平 / 垂直三个微调滑杆自动锁定**（提示"聚焦中已锁定"）——手动调整会覆盖取景、把省份切出画面，需要手动微调请先取消聚焦（缩放范围 0.3–6）。

## 联网功能说明

- 搜索分数线 / AI 补全 依赖公共 CORS 代理访问搜索引擎，网络不佳时可能全部失败——属正常现象，改用手填或 AI 粘贴模式即可。
- 除这两项外，所有功能（含导入、导出、编辑）均完全离线可用。

## 项目结构（源码，可选）

```
CengFanMap/
├─ src/           源码（index.html + style.css + js/01~07 模块 + geo 地图数据）
├─ vendor/        内联的第三方库（echarts / xlsx / html2canvas / jspdf）
├─ testdata/      导入测试用 CSV（UTF-8 与 GBK 两种编码、分数线 CSV）
├─ build.ps1      构建脚本：把源码合并为单文件
└─ dist/蹭饭图.html  构建产物（与交付物相同）
```

重新构建：

```powershell
powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -File D:\HKStudy\ProjectForFun\CengFanMap\build.ps1
```

## GitHub Pages 在线部署

仓库：`github.com/Botherain/graduation-map`（公开），站点：`https://botherain.github.io/graduation-map/`

- 仓库根目录的 `index.html` 即单文件构建产物（与交付物 `蹭饭图.html` 相同），`.nojekyll` 关闭 Jekyll 处理；`src/`、`vendor/`、`build.ps1` 为完整源码。
- 启用方式：仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch**，分支 `main`、目录 `/(root)`，保存后约 1 分钟生效。
- 构建后需同步：`Copy-Item dist\蹭饭图.html <仓库>\index.html -Force`，再提交推送（`git add -A; git commit -m "..."; git push`）。`dist/` 已被 `.gitignore` 忽略，不进仓库。
- 站点运行在 HTTPS 下，搜索分数线 / AI 补全的公共 CORS 代理照常工作；首次推送会弹出 Git Credential Manager 的 GitHub 登录窗口，登录一次即可。
